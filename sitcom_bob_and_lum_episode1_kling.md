## KLING GENERATION WORKFLOW

1. **Generate character reference images first** using the character sheets above
2. **Generate each scene** using the Kling prompts (10-30 second clips per scene)
3. **Maintain consistency** by using the same character reference images across all scenes
4. **Edit together** in order, overlay dialogue audio
5. **Add music and SFX** in post
6. **Export** at 1080p or 4K for YouTube

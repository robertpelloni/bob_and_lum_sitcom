## KLING GENERATION WORKFLOW

1. Generate **character reference images** first (Bob, Lum, apartment)
2. Generate each **scene clip** (10-30 seconds per generation)
3. Maintain **character consistency** using reference images
4. **Edit in order** — assemble scenes per episode
5. **Voice record** dialogue (or use AI voice cloning for prototype)
6. **Add music and SFX** in post
7. **Export** 1080p/4K for YouTube

### Recommended Kling Settings
- **Mode:** Professional / High Quality
- **Aspect Ratio:** 16:9
- **Duration:** 10-30 sec per clip
- **Motion:** Medium (sitcom pacing)
- **Style:** Realistic / Cinematic
- **Consistency:** Always use the same character reference images
